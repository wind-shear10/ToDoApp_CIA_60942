# Список задач — лабораторная 3

Приложение .NET MAUI для macOS (Mac Catalyst) и Windows. Данные хранятся локально в SQLite через sqlite-net-pcl.

## Возможности

- Добавление и удаление задач, выполнение и отмена выполнения.
- Выбор текстовой категории при создании, добавление своих категорий.
- Подзадачи одного уровня: добавление, удаление, выполнение.
- Автоматическое сохранение всех изменений. Удаление задачи удаляет её подзадачи.
- Выполнение родительской задачи и подзадач независимо: галочка родителя не меняет дочерние записи.
- Редактирования названий нет по условию пользователя.
