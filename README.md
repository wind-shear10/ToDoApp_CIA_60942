# Список задач — лабораторная 3

Приложение .NET MAUI для macOS (Mac Catalyst) и Windows. Данные хранятся локально в SQLite через sqlite-net-pcl. Подготовка GitHub Actions отложена по договорённости.

## Возможности

- Добавление и удаление задач, выполнение и отмена выполнения.
- Выбор текстовой категории при создании, добавление своих категорий.
- Подзадачи одного уровня: добавление, удаление, выполнение.
- Автоматическое сохранение всех изменений. Удаление задачи удаляет её подзадачи.
- Выполнение родительской задачи и подзадач независимо: галочка родителя не меняет дочерние записи.
- Редактирования названий нет по условию пользователя.

## Как устроен MVVM

`Models/TaskItem.cs` и `Category.cs` — данные и описание таблиц SQLite. `ParentId` связывает подзадачу с родителем. `[Ignore]` исключает экранную подпись категории из таблицы.

`ViewModel/MainViewModel.cs` — состояние экрана и команды. `[ObservableProperty]` генерирует публичное свойство из поля: `_newTaskTitle` превращается в `NewTaskTitle`. Сеттер сообщает экрану об изменении через `PropertyChanged`. `[RelayCommand]` превращает метод `AddTaskAsync` в `AddTaskCommand`.

`MainPage.xaml` — View. `BindingContext` указывает на ViewModel. Например, поле ввода связано с `NewTaskTitle`, а кнопка — с `AddTaskCommand`. Внутри DataTemplate контекстом является отдельная задача, поэтому команда удаления берётся у страницы через `x:Reference`, а текущая задача передаётся через `CommandParameter`.

У `CheckBox` нет свойства Command. Обработчик в `MainPage.xaml.cs` только передаёт действие во ViewModel. Он не обращается к SQLite. Односторонняя привязка позволяет сначала сохранить состояние, затем обновить модель; при ошибке галочка возвращается к сохранённому значению.

`Services/TaskDatabaseService.cs` — единственное место работы с БД. SQLiteAsyncConnection выполняет операции асинхронно. Перед каждым методом ожидается однократное создание таблиц. Удаление родителя с детьми выполняется в транзакции.

`MauiProgram.cs` связывает зависимости через DI. Приложение передаёт сервису путь `FileSystem.AppDataDirectory/tasks.db3`; Core не зависит от MAUI и тестируется отдельно.

## Проверка

Из каталога решения:

```sh
dotnet test ToDoApp.tests/ToDoApp.tests.csproj
dotnet build ToDoApp/ToDoApp.csproj -f net10.0-maccatalyst
```

На Windows целевая платформа — `net10.0-windows10.0.19041.0`. Для запуска используй соответствующую конфигурацию Rider. Mac Catalyst требует совместимый Xcode.

Тесты NUnit используют отдельный временный файл SQLite для каждого сценария. Проверяются повторное открытие БД, категории, валидация, выполнение, удаление и связь подзадач. Пользовательская база в тестах не открывается.
